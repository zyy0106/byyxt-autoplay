# byyxt-autoplay

自动播放 [byyxt.pupedu.cn](https://byyxt.pupedu.cn)(北京大学出版社「云学堂」,底层为 Readoor 平台)培训任务中全部视频的命令行工具与油猴脚本。

一条命令完成:**自动登录 → 逐个视频自动播放 → 全部完成后输出结果**。

> ⚠️ 免责声明:本工具仅限用于**你自己的账号和课程**。异常的观看时长理论上可能被平台记录,请自行评估并遵守所在机构的规则。

## 功能特性

- 自动登录:优先「统一身份认证(学号/工号)」,不可用时回退「密码登录(手机号/邮箱)」
- 图片验证码:本地 OCR 自动识别(ddddocr + OpenCV 多方案投票),失败自动换图重试,识别不出时弹出图片转人工输入
- 自动播放:16 倍速静音真实播放,绕过平台「防拖拽」限制,完成一个自动下一个
- 完成判定:同时监听平台 `pStatIf` 完成上报与视频 `ended` 事件
- 高健壮性:断点续跑、登录失效自动重登、单视频超时/报错自动跳过、防并发锁、异常退出自动清理
- 首次运行自动装依赖:Playwright、Chromium、验证码识别库,全程只需联网一次

## 快速开始

## 第 1 步:安装 Node.js
 ```
   https://nodejs.org/zh-cn
   ```
> 装完即可,不需要再打开 Node.js 。

## 第 2 步:下载本工具

1. 打开浏览器,输入网址:

   ```
   https://github.com/zyy0106/byyxt-autoplay
   ```

2. 点绿色的 **“<> Code”** 按钮,再点 **“Download ZIP”**,等它下载完。

3. 找到刚下载的 `byyxt-autoplay-main.zip`,**右键它 → 全部解压缩(Extract All)→ 解压缩**。

4. 解压后会出现一个文件夹 **`byyxt-autoplay-main`**。双击进入,里面能看到一个叫 **`start.bat`** 的文件。

## 第 3 步:准备好“任务页地址”(用的时候再复制)

1. 用浏览器正常打开云学堂网站并登录你的账号。

2. 点进你要完成的那个培训任务详情页。

3. 点一下浏览器最上面的**地址栏**(以 `https://` 开头的那一整行),按 `Ctrl + C` 复制。

> 这一步先记着怎么复制,第 4 步会要求“粘贴”。

## 第 4 步:运行程序

1. 在工具文件夹里**双击 `start.bat`**(名字是 start,图标像齿轮或白框)。

   - 如果 Windows 弹出蓝色提示“Windows 已保护你的电脑”,点 **“更多信息”**,再点 **“仍要运行”**。

2. 会弹出一个黑色窗口。第一次运行时它会自动下载组件,屏幕上会出现下载进度,等几分钟,期间**不要关窗口**。

3. 黑窗口问 **“请粘贴任务详情页地址”** 时:

   - 在黑窗口里**右键一下**(内容会自动粘贴),或按 `Ctrl + V`;
   - 按回车。

4. 接着输入:

   - **账号**(学号/工号/手机号/邮箱)→ 回车;
   - **密码** → 回车。
   - 注意:输密码时屏幕上**不显示任何字符**,这是正常的安全设计,放心输完再回车。

5. 之后完全自动:登录 → 逐个视频播放 → 自动切下一个。你什么都不用点。

6. 黑色窗口里会持续显示进度(完成百分比、剩余数量、当前正在播哪个视频),你随时瞄一眼即可。

7. 直到黑色窗口最后出现:

   ```
   Finished. If no red errors above, all done.
   ```

   (意思是“已结束:上面没有红色报错就代表全部完成”。)窗口不会自己关,点一下窗口按任意键即可关闭。

## 关于验证码

- 大多数时候程序会**自动识别验证码**;
- 如果识别不出,它会**自动打开一张验证码图片**(用系统看图工具),你照着图片把 4 个字符打进黑窗口再回车;
- 登录失败会自动“换一张”重试,最多 8 次,不用担心输错。

## 注意事项

- 运行期间**不要关闭黑色窗口**,也别让电脑进入睡眠,直到看到“运行结束”。
- 中途想停:点一下黑窗口,按 `Ctrl + C`,再按回车即可;进度存在网站上,下次重跑只会补剩下的。
- 首次下载组件需要几分钟,之后每次运行几秒钟就启动。
- 全部完成后再打开网站刷新一下,视频会显示“已完成”。

## 遇到问题看这里

| 现象 | 原因与解决 |
| --- | --- |
| 双击 start.bat 一闪而过 | 大概率没装 Node.js,回到第 1 步 |
| 黑窗口文字是乱码 | 右键窗口标题栏 → 属性,一般不影响;关掉重开一次 |
| 一直卡在下载 | 网络问题,换个网络,或稍后重试(不会重复下载) |
| 提示登录失败 | 检查账号密码;账号是学号时会自动走“统一身份认证” |
| 运行到一半断了 | 直接重新双击 start.bat,只补没完成的视频 |

## 苹果电脑 / Linux 用户

1. 同样先装 Node.js(官网下载对应系统版本);
2. 下载并解压本工具;
3. 打开“终端 / Terminal”;
4. 输入 `cd `(注意有空格),把工具文件夹**拖进终端窗口**,按回车;
5. 输入 `./start.sh` 按回车;
6. 之后和 Windows 第 4 步相同(粘贴地址、输入账号密码)。

## 实时进度

- 运行时黑色窗口会持续显示:已完成数量、百分比、剩余数量、预计剩余时间、当前视频;
- 进度同时写入 `progress.json`(实时覆盖),供其他程序读取;
- 结束后的汇总写入 `result.json`。

## 油猴脚本(替代方案)

适合平时已在浏览器登录的用户:

1. 安装 [Tampermonkey](https://www.tampermonkey.net/);
2. 新建脚本,粘贴 [byyxt-autoplay.user.js](byyxt-autoplay.user.js) 全部内容并保存;
3. 打开任务详情页即自动开始,右下角悬浮面板可暂停/停止。

## 工作原理

- 平台开启「防拖拽」,直接快进会被弹回,因此脚本用 **16 倍速静音真实播放**;
- 完成状态通过 `stat/pStatIf` 接口上报,脚本监听该接口并解密请求(平台前端内置固定 AES 密钥),服务端确认 `done=1` 后立即切换下一个视频;
- 登录走平台「统一身份认证」(如 `iaaa.pku.edu.cn`),密码由页面自带 JS 用 RSA 加密提交;
- 图片验证码由本地 ddddocr 识别,失败自动「换一张」重试并最终转人工。

## 常见问题

- **账号是学号,提示密码登录不接受?** 该通道只支持手机号/邮箱,请使用「统一身份认证」入口(程序默认优先)。
- **验证码一直识别错误?** 程序会自动换图重试;仍失败时会弹出图片让你人工输入。
- **中断了怎么办?** 完成状态保存在平台服务端,重新运行只会处理剩余视频。
- **下载依赖慢?** 先配置 npm / pip 国内镜像再运行。
